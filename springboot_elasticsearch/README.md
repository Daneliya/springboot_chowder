



版本选择

SpringBoot 版本

https://juejin.cn/post/7592438587389427750

推荐 3.3.x 或 3.5.x

Spring Boot 3.5.0 相关

| 组件名称                     | 对应版本              | 关键说明                                                     |
| ---------------------------- | --------------------- | ------------------------------------------------------------ |
| Spring Data Elasticsearch    | 5.3.x（通常是 5.3.0） | Spring Data Elasticsearch 5.3.x 是 Spring Boot 3.5.0 的默认集成版本 |
| Elasticsearch-java Client    | 8.14.x / 8.15.x       | Spring Data Elasticsearch 5.3.x 底层依赖 Elasticsearch-java 8.14+ 版本 |
| Elasticsearch 服务端（应用） | 8.14.x / 8.15.x       | 客户端与服务端版本需保持主版本一致（8.x），次版本建议匹配（如 8.15.x） |



Spring Boot 3.3.5 相关

| 组件名称                     | 对应版本              | 关键说明                                                     |
| ---------------------------- | --------------------- | ------------------------------------------------------------ |
| Spring Data Elasticsearch    | 5.1.x（核心为 5.1.6） | Spring Data Elasticsearch 5.1.x 是 Spring Boot 3.3.x 系列的标配版本 |
| Elasticsearch-java Client    | 8.12.2                | Spring Data Elasticsearch 5.1.x 底层绑定的 Elasticsearch-java 版本为 8.12.2 |
| Elasticsearch 服务端（应用） | 8.12.x（推荐 8.12.2） | 客户端与服务端需保持主版本一致（8.x），次版本建议完全匹配，避免兼容性问题 |
